## The demo sequence

This is what actually gets built and shown at the hackathon.

### Scene 1 — Empty market

Big screen:

```
SLOPSTREAM

The world's first live attention market.
```

Two companies are sitting in the queue.

### Scene 2 — First bid

ACME AI: `$5 → $10 → $15`. The leaderboard moves.

### Scene 3 — Outbid

COOLSTARTUP: `$18`. Huge animation:

```
⚡ OUTBID ⚡
```

### Scene 4 — AI generation

The winner gets a slot. On screen:

```
GENERATING AD...
```

Then:

```
Script ✓
Voice ✓
Image ✓
Video ✓
```

The ad appears.

### Scene 5 — QR challenge

The audience scans. The ad says something memorable. A question appears on everyone's phone.

### Scene 6 — Proof

Correct answers start arriving. Big screen:

```
ATTENTION VERIFIED

127 / 143 listeners

██████████████████░░

$18 CLEARED
```

### Scene 7 — Money

Animation:

```

```

### Scene 8 — The punchline

Someone bids again.

```

```

The next ad starts generating. And the entire cycle begins again.
